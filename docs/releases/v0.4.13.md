# 0.4.13 — 수집 속도·복사·스크롤 개선

- 사람인 상세 조회와 기업 홈페이지 탐색의 작업 배분을 개선했습니다. 총 7자리 중 상세용 3자리를 확보하고 홈페이지는 최대 4개를 함께 처리하며, 상세 조회가 끝나면 홈페이지 보강에 7자리를 모두 사용합니다.
- 다음 탭 준비를 요청 대기 시간과 겹쳐 불필요한 지연을 줄였습니다. 사람인 요청 간격과 기존 기업 제외 조건은 유지합니다.
- 수집 진행 바를 시작·중지 버튼 바로 왼쪽에 짧게 표시합니다. 다른 탭에 다녀와도 실제 수집 목표 건수와 진행률을 유지합니다.
- 작업 상태를 전체·상세·홈페이지로 구분해 표시합니다.
- 데이터 목록과 상세 항목에 복사 아이콘을 추가했습니다. 웹사이트와 채용공고는 실제 URL을 복사합니다.
- 하단 이메일 작성 버튼을 제거하고 복사 버튼이 기업명, 대표자명, 주소, 대표전화번호를 순서대로 4줄 복사하도록 변경했습니다. 비어 있는 값은 `-`로 표시합니다.
- 데이터 탭에서 목록이 끝나도 창 전체가 더 내려가던 문제와 개요 탭 하단이 잘리던 문제를 수정했습니다. 목록과 상세 정보는 각각 독립적으로 스크롤합니다.

동일한 50개 기업을 사용한 반복 측정과 DB 검증 결과는 [수집 엔진 운영 구조](../collection-pipeline.md)에 정리했습니다. 측정값은 외부 사이트 응답과 실행 환경에 따라 달라질 수 있습니다.

기존 앱을 다시 열고 업데이트 알림에서 **다운로드 → 재시작**을 선택하면 적용됩니다. 수동 설치는 릴리즈에 첨부된 `key-setup-0.4.13.exe`를 사용합니다.
