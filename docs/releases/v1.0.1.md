# 1.0.1 — 기업형태 필터·데이터 표시 개선

- 검색 필터에 기업형태 다중 선택을 추가했습니다. 대기업, 외국계(법인/투자), 코스닥, 주식회사, 병역특례 인증 업체를 여러 개 체크할 수 있습니다.
- 기업형태 전체 선택과 선택 해제를 지원하며, 아무 항목도 선택하지 않으면 전체 기업형태를 검색합니다. 업종·지역 조건과 함께 적용됩니다.
- 업종과 기업형태 선택 메뉴는 한 번에 하나만 열립니다. 다른 검색 필드를 누르면 기존 메뉴가 닫히며 체크한 조건은 유지됩니다.
- 데이터 목록과 회사 상세에 기업형태 및 복사 아이콘을 추가했습니다. 사람인 기업정보에 표시된 전체 분류를 수집·저장합니다.
- 기존 데이터에 기업형태가 없으면 `-`로 표시되며 재수집하면 채워집니다. 재수집 시 기업형태를 확보하지 못하면 기존 값을 유지합니다.
- 하단 복사 버튼은 기업명·대표자명·주소·대표전화번호의 4줄 형식을 유지합니다.

기존 앱을 다시 열고 업데이트 알림에서 **다운로드 → 재시작**을 선택하면 적용됩니다. 수동 설치는 첨부된 `key-setup-1.0.1.exe`를 사용합니다.
