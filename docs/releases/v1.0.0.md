# 1.0.0 — 업종 다중 선택·데이터 상세 정리

- 업종 필터에서 여러 항목을 체크할 수 있습니다. 선택한 업종 중 하나라도 해당하는 채용공고를 검색합니다.
- 업종 전체 선택과 선택 해제를 지원합니다. 아무 항목도 선택하지 않으면 전체 업종을 검색합니다.
- 선택한 업종들을 지역 조건과 함께 사람인 검색에 반영합니다. 기존 단일 업종 검색도 유지합니다.
- 데이터 탭에서 회사 선택 시 표시되던 휴대전화·이메일 행을 제거했습니다.
- 대표전화·웹사이트 등 항목별 복사와 기업명·대표자명·주소·대표전화번호의 4줄 복사는 유지합니다.

기존 앱을 다시 열고 업데이트 알림에서 **다운로드 → 재시작**을 선택하면 적용됩니다. 수동 설치는 첨부된 `key-setup-1.0.0.exe`를 사용합니다.
